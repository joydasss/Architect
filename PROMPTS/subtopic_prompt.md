# Subtopic Prompt

Use for a single subtopic (~6 pages) — the finest grain of content generation.

```text
Explain <Subtopic> from first principles.

Include: history, the problem it solves, internal implementation, a worked
example, relevant code (Java/Python/Node.js as applicable), performance,
security, best practices, trade-offs, exercises, interview questions, and
ASCII/Mermaid diagrams as needed.

Check CORE_CONCEPTS.md first — if this subtopic is owned by another chapter,
write a recap + link instead of a full explanation.

Target ~6 pages.
```
