# Exercise Prompt

Use to generate the hands-on lab, design exercise, and interview-question
sections for a chapter (sections 23-25 of the STYLE_GUIDE.md template).

```text
For the <Chapter Name> chapter, produce:

1. 5-8 interview questions ranging from conceptual to scenario-based, with
   brief model answers.
2. One hands-on lab: a step-by-step practical exercise using the chapter's
   code samples under code/<language>/.
3. One design exercise: an open-ended architecture problem relevant to the
   chapter, with a short list of evaluation criteria (not a full solution).
4. An architecture review checklist: 8-12 yes/no questions a reviewer would
   ask when validating a design that uses this chapter's topic.
```
