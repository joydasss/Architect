# Topic Prompt

Use for a single topic within a chapter (~15 pages) when a chapter is broken
into multiple focused generation passes instead of one large draft.

```text
Teach <Topic> from beginner to architect level as a section of the
<Chapter Name> chapter.

Explain the problem it solves, how it works internally, its production
usage, performance characteristics, cloud implications, debugging approach,
common pitfalls, trade-offs, and 3-5 interview questions.

Check CORE_CONCEPTS.md first — if this topic is owned by another chapter,
write a recap + link instead of a full explanation.

Target ~15 pages.
```
