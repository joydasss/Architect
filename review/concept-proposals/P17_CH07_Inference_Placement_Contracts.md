# Concept Proposals: Part 17 CH07

| Concept | Proposed Owner | Definition / Scope |
|---|---|---|
| Inference placement contract | Part 17 CH07 | A workload-specific agreement describing eligible regions or devices, data allowed to cross each boundary, model identity, readiness, capacity, request mode, and fallback when placement is unavailable. |
| Model-serving readiness state | Part 17 CH07 | A serving lifecycle contract that distinguishes process liveness from model artifact loading, warm-up, representative readiness, traffic admission, draining, and failure recovery. |
