# Concept Proposals: Part 17 CH08

| Concept | Proposed Owner | Definition / Scope |
|---|---|---|
| Workload-facing model gateway contract | Part 17 CH08 | A stable, versioned request and response boundary for model workloads that carries task intent, data class, deadline, quality tier, and attribution without claiming semantic equivalence across providers. |
| Capability-preserving model fallback | Part 17 CH08 | A governed degradation path that preserves an explicit caller contract through a compatible candidate, deterministic behavior, human queue, asynchronous completion, or declared unavailability. |
