# Concept Proposals: Part 17 CH06

| Concept | Proposed Owner | Definition / Scope |
|---|---|---|
| Planner-executor separation for agentic systems | Part 17 CH06 | A system boundary in which the model proposes structured actions while deterministic application code binds them to identity, policy, current state, scoped tools, budgets, and audit evidence. |
| Proposal-bound human approval | Part 17 CH06 | An approval contract bound to a canonical action, target resource, material parameters, evidence, and expiry; any material change or stale resource state invalidates the approval. |
