# AWS Architecture examples

Run the examples with Python 3.10 or later from the repository root:

```powershell
python code/python/aws-chapter/01_region_az_failure_domains.py
python code/python/aws-chapter/02_multi_account_guardrails.py
python code/python/aws-chapter/03_service_selection_matrix.py
python code/python/aws-chapter/04_resilience_cost_scenario.py
```

All examples use synthetic data and the standard library. They do not call AWS APIs or encode current AWS prices. The normalized scores and cost units are for demonstrating architecture decisions only.
